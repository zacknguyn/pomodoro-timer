## Design Context

### Users
Companies using pomodoro-timer to coordinate employee focus sessions integrated with GitHub. Primary users: engineering teams and managers who run focused work sessions, link sessions to commits, and measure team focus across projects.

### Use Cases
- Start/stop team pomodoro sessions
- Link session metadata to GitHub commits/issues
- Track team focus metrics and session history
- Lightweight coordination for synchronous work blocks

### Brand Personality (3 words)
breathable · adhd-compatible · logical

### Aesthetic Direction
Warm, editorial-leaning utility: soft cream canvas, generous radii (pill/circle gestures), calm typography, purposeful accents (signal orange). Both light and dark themes required. Design should feel breathable, low-distraction, and guide attention to next action.

### Font & Typography
Use curated open-source font pair (recommendation to follow). Do not use proprietary MarkForMC. Preserve editorial rules from DESIGN.md: strong hierarchy, fewer sizes, clear scale, tight display tracking where appropriate, body >=16px, WCAG AA contrast.

### Accessibility
Target: WCAG AA. Respect reduced-motion preferences. Ensure focus outlines, 200% zoom, and color contrast across themes.

### Design Principles
1. Reduce cognitive load: prioritize clarity, spacing, readable sizes, predictable layout.  
2. Intentional hierarchy: size+weight+space, not many families.  
3. Distinctive but restrained: soft cream surfaces, pill/circle gestures, reserved signal orange for accents.  
4. Performance-minded: load only used font weights, font-display: swap, avoid layout-shifting webfonts.
