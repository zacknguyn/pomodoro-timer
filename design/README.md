# Pomogit workbench proposal

The current proposal is `workbench-proposal.html`. It is a fresh visual direction built from the approved Board / Focus / Activity workflow. The earlier `board-proposal.html` remains available for comparison.

Open the HTML file directly, or serve from the repository root:

```sh
python3 -m http.server 4174 --bind 127.0.0.1
```

Visit http://127.0.0.1:4174/design/workbench-proposal.html. Add `?scene=task`, `?scene=focus`, or `?scene=activity` to jump directly to a representative state.

This is an isolated review prototype. Sample data lives only in memory; refresh resets changes. No app storage, authentication, APIs, or AWS access.

## Design rationale

The design words are **practical, composed, tactile**. The physical reference is a working desk with task slips and a clearly organized index. It uses chalk surfaces, graphite typography, and one deep red accent for intentional actions. In progress tasks receive a graphite surface to make ongoing work identifiable without a timer. Written status labels remain present.

The sidebar is a typographic index, with workspace navigation, project shortcuts, and an account footer. The board has open lanes rather than rounded containers around cards. Button outlines and a short lower shadow indicate pressability; active states press inward without moving surrounding geometry.

Barlow supplies readable working text; Bricolage Grotesque is limited to the wordmark, page headings, and timer. Fonts are served locally from `fonts/` with their SIL Open Font License files. Catalog sources: [Barlow](https://fonts.google.com/specimen/Barlow) and [Bricolage Grotesque](https://fonts.google.com/specimen/Bricolage+Grotesque).

## Review flows

1. Search or filter projects; use sidebar project shortcuts.
2. Open a task and edit title, next step, project, reference, status, and append a note.
3. Create a task and reuse or create a project name.
4. Drag cards between statuses, or use the visible status selector.
5. Start focus, pause/resume, and return to Board while the timer continues.
6. End focus immediately and optionally add a note; task completion stays separate.
7. Open Activity and recover a task from its notes.
8. Resize to mobile: labeled navigation, project/status filters, compact task list, full-screen editor.

Board, task editing, Focus, and Activity are interactive. Profile fields remain illustrative. Browser screenshots verify composition, not comprehensive keyboard or interaction testing. Full error/loading/entry states, dark theme, and production integration remain later work after visual review.

### Motion review

The avatar reveals on load and replays on hover/focus or profile-name change. Page/task selection, navigation menus, dialogs, timer panel changes, and save notices have brief opacity/transform transitions. Timer digits update without rebuilding controls, preserving keyboard focus. Reduced motion disables page transitions and paints the avatar immediately.

This revision remains a standalone proposal awaiting user approval.

### Board interaction pass
Cards expose a drag grip and instruction on desktop, lift on hover, and dim during dragging. Columns highlight valid drop destinations; moved cards animate to their new column. Move to selectors provide keyboard/mobile access. Cards include next-step context, project/status/timer badges. The floating timer, task dialog, menus, notices, and selected task context use short transitions; reduced-motion preferences disable motion.

### Task inspection and focus panel
Board cards open read-only details with Edit and Work on this buttons. Workspace rows continue selecting task context. Done tasks can be reopened explicitly. Timer starts compact while idle, expands on focus start, and collapses on stop; its compact form retains start/pause/stop controls. Navigation, account actions, and timer use a consistent inline SVG icon treatment.

### Developer Profile review
Select Profile in the preview scene picker, or open it through the avatar menu. Profile is a separate screen; Edit profile uses a dialog. Choose work explicitly selects up to three featured outcomes. Public preview includes only selected outcomes, with stats and the heatmap hidden unless sharing is enabled. The heatmap counts focus or completion and opens day breakdowns. All profile activity and results are labeled sample fixtures, not derived from GitHub or current tasks. No publishing is implemented.

### Profile customization
Use Edit profile or the Customize profile scene. Try generated Dither patterns, edit identity/links, and choose Mint/Blue/Plum/Amber. Cancel leaves saved identity unchanged. Choose featured work includes ordering controls. Profile labels distinguish visitor preview from actual publishing; idle timer is hidden on Profile. Everything resets on refresh.

### Settings review
Settings contains functioning density/motion/timer preferences, preview JSON export, and a profile shortcut. Save applies changes in memory; Cancel preserves saved preferences. Restore defaults requires Save. Session duration applies to the next timer, preserving a running countdown. Reduced motion applies to page transitions and Dither avatar reveals.

### Workflow depth
Try note drafts while switching tasks, searching, filtering projects, or pausing focus. Task-editor drafts also remain in memory when closed and reopened. Use Done status to recover completed work, or inspect it from Board/Activity. Activity records task lifecycle changes alongside notes and clears only displayed notes from the unread badge. Shortcuts: / searches, N focuses capture, ? opens help; typing and dialogs are excluded. Refresh still resets all prototype data.

### Filter toolbar
Choose Active filters in the preview picker to review applied project/status styling. Search/project/status share one toolbar with result count, removable chips, and conditional Reset. Mobile stacks search above selectors. Existing draft and filter behavior is preserved.

### Full-flow and mobile review
Try First visit → capture → Start focus → switch task → Stop → Mark done → optional note / Choose next. Mobile uses an expandable task chooser and compact focus controls; expand the timer manually when desired. The small idle timer avoids duplicating the main start action. Stress scenes: 30-task workspace, 30-task board, Completed work. Samples cover long titles, missing context, completed tasks, and multiple projects.
